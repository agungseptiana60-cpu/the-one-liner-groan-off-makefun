One original dad joke in a single line: a dad renames the home Wi-Fi "Dad's Hotspot", so every guest has to admit Dad's hot before they can get online. The program in `main.ts` writes that line (105 characters) to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
